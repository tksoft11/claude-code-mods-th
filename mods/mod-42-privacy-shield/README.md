# Mod 42: Privacy Shield TH

โหมดความเป็นส่วนตัวตอนแชร์หน้าจอหรือมีคนเดินผ่าน: เปิดแผงนาฬิกาสงบๆ บังเนื้อหา, ปิดบัง API key / รหัสผ่าน / token ในผลลัพธ์ Bash ก่อนขึ้นจอ (โมเดลก็จะเห็นเป็น •••••••• ด้วย), การ์ดโฟกัสงานเดียว และสรุปงานวันนี้จาก git log ของจริง

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/shield [ข้อความ]` | บังจอด้วยแผงนาฬิกา |
| `/shield off` | ปิดแผง |
| `/shield mask on\|off` | ปิดบังข้อมูลลับในผลลัพธ์ Bash |
| `/shield focus <งาน>` | การ์ดโฟกัสงานเดียว |
| `/shield today` | commit วันนี้จาก git |

## ติดตั้ง

```
/plugin install privacy-shield-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. รูปแบบข้อมูลลับที่ต้องปิดบัง
2. เปิด/ปิดแผงและนาฬิกาที่เดินเฉพาะตอนแผงเปิด
3. ดักผลลัพธ์ Bash ใน tool.call แล้วแก้ก่อนแสดง
4. แผงบังจอและการ์ดโฟกัส
5. คำสั่ง /shield

## หมายเหตุ

ต้นฉบับมี "จอปลอม" (Excel/อีเมล/โค้ดปลอม) ไว้หลอกคนดู ฉบับนี้ตัดออก เน้นความเป็นส่วนตัวและโฟกัสจริง การปิดบังครอบคลุมผลลัพธ์ Bash เท่านั้น ยังไม่รวมไฟล์ที่ Claude อ่านด้วย Read
