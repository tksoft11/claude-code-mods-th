# Mod 73: Typing Racer TH

แข่งพิมพ์เร็วสาย Dev: สุ่มประโยคโค้ดจริง คำสั่ง git/docker/SQL ประโยคไทย หรืออังกฤษ พิมพ์ลงช่องในแผง ตัวที่ถูกเป็นสีเขียว ผิดเป็นสีแดง รถแข่งวิ่งตามความคืบหน้า แข่งกับ "ผี" ของสถิติตัวเอง จบแล้วได้ WPM และความแม่นยำ

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/typing [code\|th\|en]` | เริ่มแข่ง (ค่าเริ่มต้น code) |
| `/typing stats` | สถิติดีที่สุด + ค่าเฉลี่ย 10 รอบ |

## ติดตั้ง

```
/plugin install typing-racer-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. วัดผล: WPM มาตรฐาน (5 ตัวอักษร = 1 คำ) และความแม่นยำ
2. แผงแข่ง: ระบายสีตามที่พิมพ์ + ลู่วิ่งของเรากับผี

## หมายเหตุ

ใช้ช่องพิมพ์ (Input) มีบน terminal, VS Code และ Desktop บนมือถือยังพิมพ์ในแผงไม่ได้
