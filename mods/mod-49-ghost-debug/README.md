# Mod 49: Ghost Debug TH

ผีไทยมาบอก error: เมื่อคำสั่งที่ Claude รันพัง Mod จะจับคู่ข้อความ error จริงกับ "ผีประจำบั๊ก" 13 ตน (กระสือ = แรมหมด, ผีพราย = พอร์ตถูกยึด, ผีกองกอย = หาไฟล์ไม่เจอ, แม่นาค = null/undefined, เปรต = stack overflow ...) แล้วเขียนอาการ สาเหตุ วิธีแก้ลงในแชตเป็นภาษาไทยปนอีสาน ถ้ารันคำสั่งเดิมผ่านในภายหลังนับเป็นการปราบผีได้บุญ และให้ Claude แปล error เป็นภาษาคนได้

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/ghost` | ทำเนียบผี + ค่าบุญ |
| `/ghost <ชื่อผี>` | รายละเอียด เช่น /ghost krasue |
| `/ghost last` | error ล่าสุดที่ผีมาสิง |
| `/ghost explain` | ให้ Claude แปล error ล่าสุดเป็นภาษาคน |
| `/ghost on\|off` | เปิด/ปิด |
| `/ghost reset confirm` | ล้างสถิติ |

## ติดตั้ง

```
/plugin install ghost-debug-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. ทำเนียบผีที่ผูกกับรูปแบบ error จริง
2. ผีปรากฏตัวด้วย $.ui.log (คุณเห็น โมเดลไม่เห็น)
3. ดูผลลัพธ์ Bash: พัง = ผีมา, ผ่าน = ปราบได้
4. แปล error ด้วย Haiku เมื่อสั่งเท่านั้น

## หมายเหตุ

ต่อยอดจากไฟล์ mod 49 ต้นฉบับ (เนื้อหาผีและภาษาอีสานคงไว้) แต่เปลี่ยนจากข้อมูลสมมติเป็นการจับ error จริง รวมไอเดีย error-decoder ไว้ด้วย บรรทัดผีแสดงในแชตของ terminal (โหมด -p จะอยู่ใน debug log)
