# Mod 48: Rainbow Friends TH

เพื่อนสายรุ้งวิ่งผ่านแผงพร้อมลากสายรุ้งเป็นคลื่น: ตัวละคร ASCII ที่ออกแบบขึ้นเอง 5 ตัว (แมว ยูนิคอร์น ช้างน้อย ปลาทอง เมฆปุย) เดินขบวนพร้อมกันได้ และข้อความสีรุ้งไล่สีวิ่ง

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/rainbow [ตัว]` | ให้เพื่อนวิ่งผ่าน: cat unicorn elephant fish cloud |
| `/rainbow parade` | ทุกตัวเดินขบวน |
| `/rainbow text <ข้อความ>` | ข้อความสีรุ้ง |
| `/rainbow list` | ดูหน้าตาทุกตัว |
| `/rainbow stop` | หยุด |

## ติดตั้ง

```
/plugin install rainbow-friends-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. ตัวละคร 2 เฟรม
2. วาดเลน: สายรุ้งเป็นคลื่น + วางตัวละครทับ และรวมช่องสีเดียวกัน
3. แผงและ timer ที่หยุดเมื่อปิดแผง
4. คำสั่ง /rainbow

## หมายเหตุ

ต้นฉบับมีตัวการ์ตูนที่มีลิขสิทธิ์ (ชินจัง โดเรมอน พาวเวอร์พัฟ ฯลฯ) ฉบับนี้ใช้ตัวละครที่วาดขึ้นใหม่ทั้งหมด แอนิเมชันหยุดเองหลังประมาณ 5 นาที
