# Mod 96: Reminders TH

ตั้งเตือนที่อยู่ข้าม session: ถึงเวลาเด้ง toast และแถบเหนือช่องพิมพ์จนกว่าจะรับทราบ ปิด Claude แล้วเปิดใหม่ เตือนที่พลาดไปจะขึ้นมาบอก ขึ้นต้นข้อความด้วย `@claude` = ถึงเวลาแล้วส่งเป็นงานให้ Claude ทำเลย

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/remind <เวลา> <ข้อความ>` | เวลา: `30m`, `2h`, `1d`, `17:30`, `พรุ่งนี้ 09:00`, `2026-11-01 14:00` |
| `/remind 18:00 @claude <งาน>` | ส่งงานให้ Claude ตอนถึงเวลา |
| `/remind list` | เตือนที่รออยู่ |
| `/remind ok` | รับทราบ |
| `/remind snooze 10m` | เลื่อน |
| `/remind del <id>` | ลบ |

## ติดตั้ง

```
/plugin install reminders-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. อ่านเวลาแบบคนพูด
2. ตรวจทุก 20 วินาทีด้วย `$.clock.every` (อ่านจาก store ทุกครั้ง เผื่อหน้าต่างอื่นแก้)
3. แถบเตือนค้างจนกว่าจะรับทราบ

## หมายเหตุ

เตือนทำงานเมื่อมี Claude Code เปิดอยู่อย่างน้อยหนึ่งหน้าต่าง
