# Mod 41: Stamp TH

ตรายางดิจิทัล 10 แบบที่ใช้กันในสำนักงาน (อนุมัติ ไม่อนุมัติ ด่วน ด่วนที่สุด ลับ เสร็จแล้ว ตรวจแล้ว ชำระแล้ว สำเนาถูกต้อง ฉบับร่าง) และตราข้อความของคุณเอง ปั๊มเล่นบน "กระดาษ" ในแผง หรือส่งออกเป็นไฟล์ SVG ที่มีลายหมึกเหมือนปั๊มจริง พร้อมวันที่ไทยและชื่อผู้ปั๊ม เอาไปวางในเอกสารหรือสไลด์ได้

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/stamp` | ดูตราทั้งหมด |
| `/stamp <ตรา>` | ปั๊มลงกระดาษในแผง เช่น /stamp approved |
| `/stamp custom <ข้อความ> [#สี]` | ตราข้อความของคุณ |
| `/stamp export <ตรา|custom ข้อความ>` | บันทึกเป็น stamp-*.svg |
| `/stamp owner <ชื่อ>` | ชื่อผู้ปั๊ม |
| `/stamp clear` | ล้างกระดาษ |

## ติดตั้ง

```
/plugin install stamp-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. ตรายางสำเร็จรูป
2. วาดตราเป็น SVG พร้อม filter ลายหมึก
3. แผงกระดาษ
4. คำสั่ง /stamp และเขียนไฟล์ด้วย $.fs.write

## หมายเหตุ

ไฟล์ SVG ใช้ฟอนต์ Sarabun หรือ Noto Sans Thai ถ้าเครื่องไม่มีจะใช้ฟอนต์ไทยที่มีแทน ตรานี้ใช้ตกแต่งเอกสาร ไม่ใช่ลายเซ็นหรือตราที่มีผลทางกฎหมาย
