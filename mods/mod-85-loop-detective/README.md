# Mod 85: Loop Detective TH

จับตอน Claude วนลองซ้ำไม่จบ: คำสั่งเดิมพังซ้ำ 3 ครั้ง, แก้ไปแก้กลับ (เปลี่ยน A เป็น B แล้ว B กลับเป็น A), แก้ไฟล์เดิมเกิน 8 ครั้งใน turn เดียว เจอแล้วเตือนเรา และกระซิบบอก Claude ผ่านผลของ tool ให้หยุดลองซ้ำแล้วหาสาเหตุจริง โหมดเข้มงวดบล็อกคำสั่งที่พังซ้ำจนกว่าเราจะพิมพ์ prompt ใหม่

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/detective` | ดูคดีของ session และคำสั่งที่กำลังพังอยู่ |
| `/detective strict on\|off` | บล็อกคำสั่งที่พังครบ 3 ครั้ง |
| `/detective reset` | ล้างตัวนับ |

## ติดตั้ง

```
/plugin install loop-detective-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. เปิดคดี: toast + เก็บไว้ดูทีหลัง
2. คำสั่ง Bash ที่พังซ้ำ: เพิ่ม `context` ให้ Claude อ่าน และ `{ deny }` ในโหมดเข้มงวด
3. แก้ไปแก้กลับ และแก้ไฟล์เดิมรัวๆ
4. แถบเตือนเหนือช่องพิมพ์

## หมายเหตุ

ตัวนับเริ่มใหม่ทุกครั้งที่เราส่ง prompt เพราะเราอาจบอกวิธีแก้ให้แล้ว
