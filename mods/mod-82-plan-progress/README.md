# Mod 82: Plan Progress TH

ติดตามแผนงานของ Claude: เมื่อ Claude จดแผนด้วย tool TodoWrite จะมีแถบความคืบหน้าเหนือช่องพิมพ์ เช่น `📝 แผน ▓▓▓▓░░░░ 3/7 · ▶ กำลังเขียนเทสต์` จับเวลาแต่ละข้อ และฉลองเมื่อเสร็จครบ

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/plan` | ดูแผนทั้งหมดพร้อมเวลาแต่ละข้อ |
| `/plan pane` | เปิดเป็นแผงข้าง |
| `/plan band on\|off` | แถบเหนือช่องพิมพ์ |

## ติดตั้ง

```
/plugin install plan-progress-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. รวมรายการใหม่กับของเดิม เก็บเวลาเริ่ม/จบ
2. ฉลองเมื่อครบ แล้วซ่อนแถบด้วย `$.clock.after`
3. ดัก `TodoWrite` ของ Claude ตัวหลัก (ข้าม subagent)
4. แถบเหนือช่องพิมพ์
5. แผงแผนงาน

## หมายเหตุ

Claude สร้างแผนเองเมื่องานมีหลายขั้นตอน งานสั้นๆ อาจไม่มีแผนให้แสดง
