# Mod 40: Mockup TH

สร้าง mockup จริงจากโลโก้ของคุณ (ไฟล์ PNG/JPG/SVG หรือข้อความ) บนสินค้า 8 แบบ: เสื้อยืด แก้วมัค แก้วเก็บความเย็น ถุงผ้า กล่องคราฟท์ ถุงกาแฟ มือถือ แล็ปท็อป ได้เป็นไฟล์ SVG ที่เปิดดูหรือส่งต่อได้ทันที เลือกสีสินค้าได้ รวมทุกแบบในหน้าเดียวได้ และทำใบสั่งงานไว้ส่งร้านสกรีน

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/mockup logo <ไฟล์>` | ใส่โลโก้ (png jpg svg webp ไม่เกิน 2 MB) |
| `/mockup text <ข้อความ>` | ใช้ข้อความแทนโลโก้ |
| `/mockup make <สินค้า> [สี]` | สร้าง mockup เช่น /mockup make shirt black |
| `/mockup all` | ทุกแบบในหน้าเดียว |
| `/mockup shop <ชื่อร้าน> [ติดต่อ]` | ร้านที่จะส่งงาน |
| `/mockup price <สินค้า> <ราคา>` | ราคาต่อชิ้นที่ร้านแจ้ง |
| `/mockup order <สินค้า> <จำนวน> [รายละเอียด]` | เพิ่มรายการสั่ง |
| `/mockup order / order export / order clear` | ดู / ส่งออก / ล้างใบสั่งงาน |
| `/mockup reset confirm` | ล้างข้อมูลทั้งหมด |

## ติดตั้ง

```
/plugin install mockup-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. วาดสินค้าด้วย SVG path และกำหนดกรอบวางโลโก้
2. ฝังรูปเป็น data URI ด้วย $.fs.read แบบ bytes และเลือกสีโลโก้ตามความสว่างของพื้น
3. ใบสั่งงานที่ใช้ราคาที่ผู้ใช้ใส่เองเท่านั้น
4. คำสั่ง /mockup

## หมายเหตุ

Mod ไม่ได้สั่งซื้อหรือจ่ายเงินให้ร้านไหน ราคาไม่มีค่าเริ่มต้น ใส่เองตามที่ร้านแจ้ง mockup เป็นภาพประกอบเพื่อให้เห็นตำแหน่งโลโก้ ไม่ใช่ภาพถ่ายจริง
