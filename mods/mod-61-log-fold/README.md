# Mod 61: Log Fold TH

พับ output ยาวของคำสั่ง Bash (เกิน 30 บรรทัด) ให้เหลือหัว 10 + ท้าย 10 บรรทัด แต่ดึงบรรทัด error / warning ที่ซ่อนอยู่ตรงกลางขึ้นมาแสดงพร้อมเลขบรรทัด ระบายสีแดง/เหลือง/เขียว กด ctrl+o ยังเห็น output ทั้งหมดตามเดิม และสิ่งที่ Claude อ่านไม่เปลี่ยน

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/logfold` | สถานะ + จำนวนครั้งที่พับ |
| `/logfold on\|off` | เปิด/ปิด |

## ติดตั้ง

```
/plugin install log-fold-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. แบ่ง output เป็นหัว / บรรทัดสำคัญที่ถูกพับ / ท้าย
2. วาด ToolResult ใหม่เฉพาะตอนไม่ได้ขยายดู

## หมายเหตุ

เปลี่ยนแค่การแสดงผลบนจอ ไม่แก้ผลลัพธ์ที่โมเดลได้รับ
