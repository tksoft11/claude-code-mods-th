# Mod 93: Collision Guard TH

กันชนระหว่าง Claude หลายหน้าต่าง: เปิด Claude 2 หน้าต่างในโปรเจกต์เดียวกันแล้วแก้ไฟล์เดียวกัน งานของอีกหน้าต่างอาจหายโดยไม่รู้ตัว Mod นี้จดทุกการแก้ลงสมุดกลาง `.claude/collision-guard.json` และก่อนแก้ไฟล์ที่ Claude อีกหน้าต่างเพิ่งแก้ภายใน 30 นาที จะถามเราก่อนว่าแก้ต่อหรือยกเลิก

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/collision` | ดูไฟล์ที่หน้าต่างอื่นเพิ่งแก้ |
| `/collision window <นาที>` | ช่วงเวลาที่ถือว่า "เพิ่งแก้" |

## ติดตั้ง

```
/plugin install collision-guard-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. สมุดกลางของโปรเจกต์ (ทุกหน้าต่างอ่าน/เขียนเล่มเดียวกัน)
2. ก่อนแก้ ตรวจว่าหน้าต่างอื่นเพิ่งแก้ไหม แล้วถามด้วย `$.ui.ask`
3. ดูว่าใครแก้อะไรอยู่

## หมายเหตุ

ถ้าเลือกยกเลิก Claude จะได้รับข้อความให้อ่านไฟล์ใหม่และถามเราว่าจะประสานงานอย่างไร ควรใส่ `.claude/collision-guard.json` ใน `.gitignore`
