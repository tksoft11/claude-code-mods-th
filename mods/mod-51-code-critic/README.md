# Mod 51: Code Critic TH

AI ตัวที่สอง (Haiku) รีวิวโค้ดที่ Claude เพิ่งแก้: อ่าน git diff ของไฟล์ที่แก้ในรอบนั้น หาเฉพาะปัญหาจริง (บั๊ก ช่องโหว่ ข้อมูลลับ การจัดการ error ที่หาย) ไม่ติเรื่องรสนิยม เลือกโทนตรงไปตรงมาหรือแบบน่ารักได้ ส่งผลรีวิวให้ Claude แก้ต่อได้ด้วยคำสั่งเดียว และเตือนเมื่อไฟล์เดียวถูกแก้วนเกิน 4 รอบใน 1 ชั่วโมง

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/critic` | รีวิวไฟล์ที่ Claude แก้ในรอบล่าสุด |
| `/critic file <path>` | รีวิวไฟล์ที่ระบุ |
| `/critic fix` | ส่งผลรีวิวให้ Claude ตรวจและแก้ |
| `/critic auto on\|off` | รีวิวเองทุกครั้งที่ Claude แก้ไฟล์เสร็จ (ค่าเริ่มต้น: ปิด) |
| `/critic tone plain\|cute` | โทนการรีวิว |
| `/critic churn` | ไฟล์ที่ถูกแก้วนบ่อย |

## ติดตั้ง

```
/plugin install code-critic-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. จำไฟล์ที่ถูกแก้และนับการแก้วน
2. รวบรวม git diff (หรือเนื้อไฟล์ถ้าไม่อยู่ใน git)
3. สั่ง Haiku ให้ชี้เฉพาะปัญหาจริง
4. ดัก Edit/Write ที่สำเร็จ
5. คำสั่ง /critic และส่งต่อด้วย $.prompt.submit

## หมายเหตุ

รีวิวอัตโนมัติใช้ token เพิ่มทุกครั้งที่ Claude แก้ไฟล์ จึงปิดไว้เป็นค่าเริ่มต้น ผลรีวิวโมเดลหลักไม่เห็นจนกว่าคุณสั่ง /critic fix และ Claude จะตรวจก่อนว่าแต่ละข้อจริงไหม
