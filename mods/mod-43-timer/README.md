# Mod 43: Timer TH

จับเวลาหลายตัวพร้อมกัน: นับถอยหลัง ("มาม่า 3m", "ประชุม 1:30:00") ครบแล้วเด้งเตือน, stopwatch ที่หยุดชั่วคราวได้ และบันทึกเวลาทำงานแยกโปรเจกต์ แล้วสรุปเป็นรายงานรายวัน/รายสัปดาห์ แผงแสดงทุกตัวแบบสด

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/timer start <ชื่อ> <เวลา>` | นับถอยหลัง (90s 25m 1h30m 1:30:00) |
| `/timer stopwatch <ชื่อ>` | จับเวลาเดินหน้า |
| `/timer work <โปรเจกต์>` | เริ่มบันทึกเวลาทำงาน |
| `/timer stop <ชื่อ> \| stop all` | หยุด (งานจะถูกบันทึก) |
| `/timer pause\|resume <ชื่อ>` | หยุดชั่วคราว / ต่อ |
| `/timer report [week]` | สรุปเวลาทำงานแยกโปรเจกต์ |

## ติดตั้ง

```
/plugin install timer-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. อ่านระยะเวลาแบบคน
2. timer ทุก 1 วินาทีที่เปิดเฉพาะตอนมีตัวจับเวลา
3. รายงานเวลาทำงานแยกโปรเจกต์
4. แผงตัวจับเวลา
5. คำสั่ง /timer

## หมายเหตุ

ตัวจับเวลาทำงานเฉพาะตอนเปิด Claude Code อยู่ ส่วนบันทึกเวลาทำงานที่หยุดแล้วเก็บข้าม session Pomodoro อยู่ใน Mod 31
