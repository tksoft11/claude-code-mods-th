# Mod 13: Nokia Games TH

เกมงูและ Tetris จอสีเขียวแบบ Nokia 3310 เล่นในแผงข้าง Claude Code เกมขยับเองตามเวลา และกด `w` `a` `s` `d` บนคีย์บอร์ดเพื่อบังคับได้เลย High Score จะจำไว้ข้าม session

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/game snake [กว้าง] [สูง]` | เริ่มเกมงู (ค่าเริ่มต้น 20x12) |
| `/game tetris` | เริ่ม Tetris |
| `/game pause` / `resume` / `quit` | หยุด / เล่นต่อ / ออก |
| `/game scores` | ดู High Score (`/game scores clear` ล้าง) |
| `/game demo` | ดูหน้าจอตัวอย่างแบบข้อความ |
| `/game up` / `down` / `left` / `right` / `drop` | บังคับด้วยคำสั่ง (ใช้ตอนกดปุ่มในแผงไม่ได้) |

ปุ่มในแผง (กดบนคีย์บอร์ดได้ทันที):

| ปุ่ม | เกมงู | Tetris |
|---|---|---|
| `w` | ขึ้น | หมุน |
| `a` | ซ้าย | เลื่อนซ้าย |
| `s` | ลง | ลงเร็ว |
| `d` | ขวา | เลื่อนขวา |
| `x` | - | ทิ้งลงสุด |
| `p` | หยุด / เล่นต่อ | หยุด / เล่นต่อ |
| `r` | เริ่มใหม่ | เริ่มใหม่ |

กด Esc เพื่อปิดแผง (เกมจะหยุดไว้ พิมพ์ `/game resume` เพื่อเล่นต่อ)

## ติดตั้ง

```
/plugin install nokia-games-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. แยก game state (ตำแหน่งงู, อาหาร, คะแนน) ออกจากการวาด
2. ขยับงูทีละก้าว: เช็คชนขอบ, ชนตัวเอง, กินอาหาร และกันการหันกลับ 180 องศา
3. Tetris: เช็คว่าชิ้นวางได้ไหม และหมุนชิ้น 90 องศา
4. Tetris: ตก, วางชิ้นลงกระดาน, ลบแถวที่เต็ม และนับคะแนน
5. Game loop ด้วย `$.clock.every` และเก็บ High Score ใน `$.store`
6. วาดจอ Nokia ด้วย `Box` (สีพื้น + ขอบ) และทำปุ่มคีย์ลัดด้วย `Button hotkey`
7. คำสั่ง `/game` และการบังคับเกมด้วยคำสั่ง

## หมายเหตุ

- ปุ่ม `w` `a` `s` `d` ใช้ได้เมื่อแผงเกมถูกโฟกัสอยู่ (แผงจะถูกโฟกัสเองตอนเริ่มเกม) ถ้ากลับไปพิมพ์ที่ช่องข้อความ ให้คลิกที่แผงหรือกด ctrl+x แล้ว tab เพื่อกลับไปที่แผง
- เกมวาดด้วยตัวอักษร ไม่ใช่พิกเซลจริง ความเร็วเกมขึ้นกับการวาดของหน้าจอ
