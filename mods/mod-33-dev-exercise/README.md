# Mod 33: Dev Exercise TH

ท่ายืดเหยียดแก้ Office Syndrome 12 ท่าที่ทำได้บนเก้าอี้ (คอ บ่า ไหล่ หลัง ข้อมือ ตา ขา) แผงพาทำทีละท่าพร้อมนับถอยหลัง แล้วไปท่าถัดไปเอง มีชุดสำเร็จรูป 4 ชุด เตือนให้ลุกขยับ และนับว่าวันนี้ทำไปกี่ท่า

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/exercise` | ชุดเร็ว 3 นาที |
| `/exercise neck / typing / back` | ชุดคอบ่าไหล่ / ข้อมือ+ตา / หลัง |
| `/exercise do <ท่า>` | ทำท่าเดียว |
| `/exercise list` | ทุกท่า |
| `/exercise remind on [นาที] / off` | เตือนลุกขยับ (ค่าเริ่มต้นทุก 60 นาที) |
| `/exercise today` | วันนี้ทำไปกี่ท่า |

## ติดตั้ง

```
/plugin install dev-exercise-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. คลังท่าและชุดท่า
2. พาทำทีละท่าด้วย timer แล้วไปท่าถัดไปเอง
3. แผงพาทำ แถบนับถอยหลัง และปุ่มข้าม (n)
4. คำสั่ง /exercise

## หมายเหตุ

เป็นท่ายืดเหยียดทั่วไป ไม่ใช่คำแนะนำทางการแพทย์ ถ้าเจ็บหรือชาให้หยุด แล้วปรึกษาแพทย์หรือนักกายภาพบำบัด
