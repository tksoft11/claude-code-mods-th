# Mod 89: Achievements TH

ปลดล็อกความสำเร็จ 31 อย่างจากการทำงานกับ Claude เช่น 🦉 นกฮูกราตรี (ทำงานหลังเที่ยงคืน), 🐛 นักฆ่าบั๊ก (เทสต์ที่พังกลับมาผ่าน), 🌏 พหุภาษา (แก้ไฟล์ 5 ภาษา), 💎 ไร้ที่ติ (tool 50 ครั้งไม่พังเลย), 👑 หัวหน้าทีม (ส่ง subagent 3 ตัว), 🇹🇭 หัวใจไทย (สั่งงานภาษาไทย 50 ครั้ง) ปลดล็อกแล้วเด้งฉลอง และเก็บไว้ข้าม session

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/badges` | เปิดตู้โชว์ในแผง |
| `/badges list` | ดูเป็นข้อความ พร้อมวิธีปลดอันที่ยังล็อก |

## ติดตั้ง

```
/plugin install achievements-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. รายการความสำเร็จ: แต่ละอันเป็นฟังก์ชันตรวจเงื่อนไข
2. ตรวจทุกครั้งที่มีอะไรเกิดขึ้น แล้วฉลองอันที่เพิ่งได้
3. prompt ของเรา: เวลา ภาษา มารยาท
4. tool: แก้ไฟล์ git เทสต์ เว็บ
5. จังหวะของรอบคำตอบ
6. ตู้โชว์

## หมายเหตุ

นับจาก event ของ engine ในเครื่อง ไม่ส่งข้อมูลไปไหน ความสำเร็จเก็บใน `$.store` ของ mod
