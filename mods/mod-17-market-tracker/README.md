# Mod 17: Market Tracker TH

ดูราคาทองคำแท่งและทองรูปพรรณของไทย ทองโลก หุ้น SET และหุ้นอเมริกา คริปโต (ราคาเป็นบาท) และค่าเงิน USD/THB จากแหล่งข้อมูลจริง ทุกราคาบอกแหล่งที่มาและเวลาของข้อมูล มี watchlist ในแผงด้านข้าง พอร์ตที่คำนวณกำไร/ขาดทุนรวมเป็นบาท และแจ้งเตือนเมื่อราคาข้ามระดับที่ตั้งไว้

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/market` | watchlist + เปิดแผง |
| `/market gold` | ทองคำแท่ง ทองรูปพรรณ และทองโลก |
| `/market oil` | น้ำมันดิบ WTI และ Brent (USD ต่อบาร์เรล) |
| `/market crypto [BTC ETH ...]` | คริปโต ราคาเป็นบาท และการเปลี่ยนแปลง 24 ชม. |
| `/market stock PTT.BK AAPL` | หุ้น (หุ้นไทยลงท้าย `.BK`) |
| `/market set PTT KBANK` | หุ้นไทยแบบไม่ต้องใส่ `.BK` |
| `/market stocks` | หุ้นไทยขนาดใหญ่ที่คนดูบ่อย |
| `/market fx` | ค่าเงิน USD/THB |
| `/market BTC PTT.BK` | ดูราคาตามชื่อที่พิมพ์ |
| `/market watch add\|remove <ชื่อ>` | จัดการ watchlist |
| `/market buy <ชื่อ> <จำนวน> <ราคาต่อหน่วย>` | บันทึกเข้าพอร์ต |
| `/market sell <ชื่อ>` | เอาออกจากพอร์ต |
| `/market portfolio` | กำไร/ขาดทุน รวมเป็นบาท |
| `/market alert <ชื่อ> above\|below <ราคา>` | แจ้งเตือนเมื่อราคาข้ามระดับ (เช็คทันที แล้วเช็คทุก 5 นาที) |
| `/market alerts` / `alert remove <id>` | ดู / ลบการแจ้งเตือน |

ชื่อพิเศษ: `GOLD-BAR` (ทองคำแท่ง), `GOLD` (ทองรูปพรรณ), `XAU` (ทองโลก), `OIL`/`WTI` และ `BRENT` (น้ำมัน), `SILVER` (เงิน), `USDTHB`, `BTC` `ETH` `SOL` `BNB` `XRP` `DOGE` `ADA` `USDT`

## ติดตั้ง

```
/plugin install market-tracker-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## แหล่งข้อมูล

| ข้อมูล | แหล่ง | หมายเหตุ |
|---|---|---|
| คริปโต | [CoinGecko API](https://www.coingecko.com/en/api) | ฟรี มีจำกัดจำนวนครั้งต่อนาที |
| ค่าเงิน | [open.er-api.com](https://www.exchangerate-api.com/docs/free) | อัปเดตวันละครั้ง |
| ทองไทย | `api.chnwt.dev/thai-gold-api` | ไม่เป็นทางการ อ้างอิงราคาจากเว็บสมาคมค้าทองคำ |
| หุ้นและทองโลก | Yahoo Finance chart API | ไม่เป็นทางการ อาจล่าช้า ~15 นาที |

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. ดึงข้อมูลจากหลายแหล่ง แล้วแปลง JSON ที่หน้าตาต่างกันให้เป็นรูปแบบ `Quote` เดียวกัน
2. เลือกแหล่งข้อมูลจากชื่อ, cache 60 วินาที และดึงพร้อมกันด้วย `Promise.all`
3. จัดรูปแบบตัวเลขและเวลา
4. watchlist, พอร์ต และแจ้งเตือน เก็บใน `$.store` และเช็คแจ้งเตือนด้วย `$.clock.every`
5. แผง watchlist ที่มีปุ่มรีเฟรช

## หมายเหตุ

- ⚠️ ข้อมูลอาจล่าช้าหรือคลาดเคลื่อน ไม่ใช่คำแนะนำการลงทุน
- แจ้งเตือนจะทำงานเฉพาะตอนที่เปิด Claude Code อยู่ เมื่อแจ้งแล้วจะลบตัวเองออก
- API ที่ไม่เป็นทางการอาจเปลี่ยนรูปแบบหรือเลิกให้บริการได้ ถ้าราคาไหนดึงไม่ได้ จะขึ้น ⚠️ บอกแทนการแสดงตัวเลขผิด
