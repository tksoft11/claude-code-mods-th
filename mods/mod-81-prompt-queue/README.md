# Mod 81: Prompt Queue TH

คิวงานต่อท้าย: สั่ง `/after <งาน>` ไว้ล่วงหน้า พอ Claude ตอบงานปัจจุบันเสร็จจะส่งงานถัดไปให้เอง ไม่ต้องนั่งรอ และไม่ขัดงานที่กำลังทำ ถ้างานล่าสุดถูกหยุดหรือ error คิวจะหยุดรอให้ตรวจก่อน และ `/aside <คำถาม>` ถาม fork ของ session ในแผงข้าง รู้บริบทเดิมทั้งหมดแต่ไม่เข้าบทสนทนาหลัก

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/after <งาน>` | ต่อคิว (ถ้า Claude ว่างอยู่จะส่งทันที) |
| `/after` | ดูคิว |
| `/after go` | ส่งงานถัดไป หรือไปต่อหลังคิวหยุด |
| `/after drop <ลำดับ>` | เอางานออกจากคิว |
| `/after clear` | ล้างคิว |
| `/aside <คำถาม>` | ถามข้างทางในแผง |

## ติดตั้ง

```
/plugin install prompt-queue-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. ส่งงานถัดไปด้วย `$.prompt.submit`
2. ถามข้างทางด้วย `$.model.fork`
3. รู้ว่า Claude ทำงานอยู่ไหม และส่งงานต่อตอนจบ turn
4. แถบคิวเหนือช่องพิมพ์
5. แผงคำถามข้างทาง

## หมายเหตุ

คิวอยู่ในหน่วยความจำของ session เปิด session ใหม่คิวจะเริ่มว่าง `/aside` ใช้ได้หลังคำตอบแรกของ Claude
