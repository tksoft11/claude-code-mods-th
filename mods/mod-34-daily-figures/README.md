# Mod 34: Daily Figures TH

บุคคลสำคัญประจำวันจากข้อมูลจริงของ Wikipedia "On this day": คัดคนที่เกิดวันนี้ในอาชีพที่สร้างแรงบันดาลใจ (นักวิทยาศาสตร์ นักประดิษฐ์ นักเขียน ผู้นำ ศิลปิน ...) แล้วให้ Claude สรุปเป็นภาษาไทยว่าเขาเป็นใคร ทำอะไรสำคัญ และข้อคิดสำหรับ Dev ค้นประวัติคนอื่นได้ด้วย

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/figure` | บุคคลประจำวันนี้ |
| `/figure list` | ทุกคนที่เกิดวันนี้ (คัดแล้ว) |
| `/figure random` | สุ่มอีกคน |
| `/figure date <วัน/เดือน>` | ดูวันอื่น |
| `/figure search <ชื่อ>` | ประวัติคนที่สนใจ (ชื่อภาษาอังกฤษ) |
| `/figure fav [ชื่อ]` | คนที่ชอบ |

## ติดตั้ง

```
/plugin install daily-figures-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. ดึงข้อมูลจาก Wikimedia On this day API
2. คัดและเลือกคนประจำวัน (ได้คนเดิมทั้งวัน)
3. ให้ Claude สรุปเป็นไทยโดยใช้เฉพาะข้อมูลจาก Wikipedia
4. คำสั่ง /figure

## หมายเหตุ

API On this day รองรับเฉพาะ Wikipedia ภาษาอังกฤษ จึงดึงจากฉบับอังกฤษแล้วสรุปเป็นไทย ส่วน "ข้อคิด" เป็นการตีความของ Claude
