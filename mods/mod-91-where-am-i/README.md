# Mod 91: Where Am I TH

เข็มทิศงาน: หลัง Claude ตอบจบแต่ละครั้ง Haiku จะสรุปเหนือช่องพิมพ์ว่า 🎯 เป้าหมาย · ✅ เสร็จแล้ว · ⏳ รอคุณ · ➡️ ต่อไป กลับจากพักกาแฟก็รู้ทันทีว่างานถึงไหน ช่อง "รอคุณ" เป็นสีส้มเด่นเมื่อ Claude ถามหรือรออะไรจากเรา

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/where` | ดูสรุปเต็ม |
| `/where on\|off` | เปิด/ปิด |
| `/where compact on\|off` | แสดงบรรทัดเดียว |

## ติดตั้ง

```
/plugin install where-am-i-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. ให้ Haiku สรุปเป็น 4 ช่อง (JSON)
2. จำคำสั่งของเรา และสรุปใหม่ตอนจบ turn โดยไม่ทำให้ turn ช้า
3. เข็มทิศเหนือช่องพิมพ์

## หมายเหตุ

ใช้ Haiku 1 ครั้งต่อคำตอบ (ค่าใช้จ่ายน้อยมาก)
