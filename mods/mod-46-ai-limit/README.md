# Mod 46: AI Limit TH

ดูโควตา Claude แบบน่ารัก: ลิมิตหน้าต่าง 5 ชั่วโมงและ 7 วันจากตัวเลขจริงของ Claude Code พร้อมเวลารีเซ็ต การใช้ context และค่าใช้จ่ายของ session แมวแม่มดน้อยเปลี่ยนหน้าตามโควตาที่เหลือ ย่อในแถบสถานะ และเตือนก่อนเต็ม (ค่าเริ่มต้น 80% และ 95%)

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/ailimit` | ดูโควตา + เปิดแผงแมวแม่มด |
| `/ailimit status on\|off` | ย่อในแถบสถานะ |
| `/ailimit warn <%> <%>` | ตั้งเกณฑ์เตือน |
| `/ailimit budget <ดอลลาร์>` | งบค่าใช้จ่ายต่อวัน รวมทุก session เตือนที่ 80% และเมื่อเกิน / `budget off` |

## ติดตั้ง

```
/plugin install ai-limit-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. แมวแม่มดตามระดับโควตา
2. แถบสถานะและการเตือนตอนข้ามเกณฑ์
3. รับตัวเลขจาก event session.measure
4. แผงแมวแม่มด
5. คำสั่ง /ailimit

## หมายเหตุ

ลิมิต 5 ชั่วโมง/7 วันมีเฉพาะแพ็กเกจสมาชิก (ใช้ API key จะไม่มี) และจะมีตัวเลขหลังคำตอบแรกของ session ได้แรงบันดาลใจจากแอป PIKORI ของคุณ Ron Thitisak
