# Mod 84: Time Machine TH

ย้อนเวลาไฟล์ที่ Claude แก้: ทุกครั้งที่ Claude ใช้ Edit / Write / NotebookEdit จะถ่ายภาพไฟล์ก่อนและหลังแก้ไว้ เป็นไทม์ไลน์ทีละขั้น ดูได้ว่าขั้นไหนเปลี่ยนอะไร และย้อนกลับไปขั้นไหนก็ได้ ไม่ต้องพึ่ง git และย้อนได้แม้ยังไม่ commit ไฟล์ที่ Claude สร้างใหม่ ย้อนแล้วจะถูกลบ

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/tm` | ไทม์ไลน์การแก้ไฟล์ |
| `/tm diff <ขั้น>` | ดูว่าขั้นนั้นเปลี่ยนอะไร |
| `/tm undo [ขั้น]` | ย้อนไฟล์ไปก่อนขั้นนั้น (ไม่ใส่ = ขั้นล่าสุด) |
| `/tm pane` | เปิดแผงไทม์ไลน์ |

## ติดตั้ง

```
/plugin install time-machine-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. diff แบบบรรทัด (LCS)
2. ถ่ายภาพไฟล์ก่อนและหลังแก้
3. ย้อนไฟล์กลับ (ลบไฟล์ใหม่ด้วย `$.process.run`)
4. ดักทุก tool ที่แก้ไฟล์

## หมายเหตุ

เห็นเฉพาะการแก้ผ่าน tool แก้ไฟล์ ไม่เห็นการแก้ผ่าน Bash ไทม์ไลน์อยู่ในหน่วยความจำของ session (ล่าสุด 200 ขั้น ไฟล์เกิน 1 MB ไม่เก็บ) ย้อนขั้นที่มีขั้นหลังจากนั้นของไฟล์เดียวกัน ขั้นหลังจะถูกย้อนไปด้วย
