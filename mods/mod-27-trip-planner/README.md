# Mod 27: Trip Planner TH

ผู้ช่วยวางแผนเที่ยว: ให้ Claude วางแผนทริปรายวันพร้อมงบประมาณและของที่ต้องเตรียม แล้วบันทึกเป็นไฟล์ Markdown, ทำลิงก์ค้นตั๋วเครื่องบิน รถทัวร์ รถไฟ และที่พักไปยังเว็บจองจริง และเก็บตั๋วที่จองแล้ว (เลขที่จอง ที่นั่ง) พร้อมนับถอยหลัง เปิด Claude Code วันก่อนเดินทางจะเด้งเตือน

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/trip plan เชียงใหม่ 3 งบ 8000 ชอบคาเฟ่` | ให้ Claude วางแผน บันทึกเป็น trip-เชียงใหม่.md |
| `/trip search กรุงเทพ ภูเก็ต 15/12 [flight\|bus\|train\|hotel\|all]` | ลิงก์ค้นตั๋วและที่พัก |
| `/trip add บิน DMK-CNX 15/12 08:30 FD3433 ที่นั่ง 12A` | เก็บตั๋ว (บิน รถทัวร์ รถไฟ รถตู้ เรือ) |
| `/trip tickets` | ตั๋วที่จะถึง พร้อมนับถอยหลัง |
| `/trip remove <id>` | ลบตั๋ว |

## ติดตั้ง

```
/plugin install trip-planner-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. แปลงวันที่ (พ.ศ., วันนี้/พรุ่งนี้, ไม่ใส่ปีแล้ววันผ่านไปแล้ว = ปีหน้า)
2. สร้างลิงก์ค้นหาไปเว็บจองจริง
3. ให้ Claude วางแผนด้วย $.model.complete (มี model สำรอง)
4. คำสั่ง /trip และการเตือนตอนเปิด session

## หมายเหตุ

Mod จองตั๋วหรือรับเงินเองไม่ได้ เพราะไม่มี API สาธารณะของสายการบิน บขส. หรือ รฟท. จึงพาไปหน้าค้นหาของเว็บจองแทน แผนเที่ยวที่ Claude เขียน (ใช้ haiku) อาจมีรายละเอียดคลาดเคลื่อน เช่น เวลาเปิด ราคา หรือที่ตั้งร้าน ตรวจกับแหล่งข้อมูลจริงก่อนเดินทาง
