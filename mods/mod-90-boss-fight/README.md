# Mod 90: Boss Fight TH

เทสต์พัง = บอสโผล่! เมื่อ Claude รันเทสต์ (npm test, pytest, go test, cargo test, jest, vitest, dotnet test ...) แล้วพัง บอสผีไทยจะโผล่เหนือช่องพิมพ์ เช่น ทศกัณฐ์บั๊กสิบหน้า, พญานาค NullPointer, กระสือ Segfault HP เท่าจำนวนเทสต์ที่พัง รันครั้งถัดไปพังน้อยลง = ฟาดโดน (บอสสั่น) พังมากขึ้น = บอสโกรธ HP เพิ่ม ผ่านหมด = K.O.! ได้ของรางวัลสุ่ม และนับสถิติบอสที่ปราบได้ข้าม session

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/boss` | สถานะบอสและสถิติ |
| `/boss flee` | หนีบอส (ซ่อนบอสตัวปัจจุบัน) |

## ติดตั้ง

```
/plugin install boss-fight-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. อ่านจำนวนเทสต์ที่พังจากบรรทัดสรุปสุดท้ายของ output
2. การต่อสู้: เกิด ฟาด โกรธ KO
3. ดักคำสั่งเทสต์
4. วาดบอสเหนือช่องพิมพ์ พร้อมสั่นตอนโดนฟาดด้วย `$.clock.after`

## หมายเหตุ

ถ้าอ่านจำนวนจาก output ไม่ออกแต่คำสั่งพัง นับเป็น 1
