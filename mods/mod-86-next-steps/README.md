# Mod 86: Next Steps TH

เดา prompt ถัดไปให้: ทุกครั้งที่ Claude ตอบจบ Haiku จะอ่านคำสั่งล่าสุดกับคำตอบ แล้วเสนอ prompt ถัดไป 3 ข้อเหนือช่องพิมพ์ ช่องพิมพ์ว่างอยู่กด `1` `2` `3` เพื่อใส่ข้อนั้นลงช่อง (แก้ต่อได้ก่อนส่ง) กด `0` ปิด ข้อแรกยังขึ้นเป็นคำแนะนำจางในช่องพิมพ์ กด Tab รับได้ ตอบภาษาเดียวกับที่เราพิมพ์

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/next` | ดูข้อเสนอล่าสุด |
| `/next 1\|2\|3` | ใส่ข้อนั้นลงช่องพิมพ์ |
| `/next on\|off` | เปิด/ปิด |

## ติดตั้ง

```
/plugin install next-steps-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. ให้ Haiku เดา prompt ถัดไปด้วย `$.model.complete`
2. เดาหลังจบ turn โดยไม่ทำให้ turn ช้า
3. ดักปุ่มในช่องพิมพ์ด้วย `prompt.edit`
4. แถบข้อเสนอเหนือช่องพิมพ์

## หมายเหตุ

ใช้ Haiku 1 ครั้งต่อคำตอบ (ค่าใช้จ่ายน้อยมาก) ขณะมีข้อเสนออยู่ การพิมพ์ 0-3 เป็นตัวแรกในช่องว่างจะถูกใช้เป็นทางลัด ถ้าอยากพิมพ์ตัวเลขจริงให้กด 0 ปิดก่อน
