# Mod 63: Progress Plant TH

ต้นไม้ในแถบสถานะที่โตตามจำนวนบรรทัดที่ Claude เขียนให้วันนี้ 🌰 → 🌱 20 → 🌿 100 → 🪴 250 → 🌳 500 → 🌸 1000 → 🍎 2000 บรรทัด เด้งฉลองทุกครั้งที่ขึ้นขั้นใหม่ ขึ้นวันใหม่ต้นไม้ของเมื่อวานย้ายไปปลูกในสวน ดูย้อนหลังได้

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/plant` | ต้นไม้วันนี้ + ความคืบหน้า |
| `/plant garden` | สวน 30 วันล่าสุด |
| `/plant on\|off` | แสดง/ซ่อนในแถบสถานะ |

## ติดตั้ง

```
/plugin install progress-plant-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. นับบรรทัดจาก Write / Edit / MultiEdit ที่สำเร็จ
2. ขั้นของต้นไม้และการย้ายลงสวนเมื่อขึ้นวันใหม่

## หมายเหตุ
