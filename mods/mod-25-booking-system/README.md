# Mod 25: Booking System TH

ระบบจองห้องประชุม โต๊ะร้านอาหาร สนามกีฬา หรือคิวช่าง ลงทะเบียนสิ่งที่ให้จองพร้อมราคาต่อชั่วโมง จองตามวันและช่วงเวลา กันจองซ้อนอัตโนมัติ (บอกช่วงว่างให้เมื่อชน) คิดราคาให้ ดูตารางรายวันแบบปฏิทินในแผง สรุปรายได้รายเดือน และส่งออก CSV ที่ Excel อ่านภาษาไทยได้ ข้อมูลเก็บในเครื่องเท่านั้น

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/book resource add ห้องA ห้องประชุม 300` | เพิ่มสิ่งที่ให้จอง ราคา 300 บาท/ชม. |
| `/book resource list / remove <ชื่อ>` | ดู/ลบ |
| `/book add ห้องA พรุ่งนี้ 13:00-15:00 คุณสมชาย ประชุมทีม` | จอง (วัน: วันนี้, พรุ่งนี้, 25/10, 25/10/2569, 2026-10-25) |
| `/book free ห้องA พรุ่งนี้` | ช่วงที่ว่าง |
| `/book cancel <id> / done <id>` | ยกเลิก / ปิดงาน |
| `/book day [วัน]` | ตารางรายวัน + เปิดแผง |
| `/book list [วัน]` | รายการจอง |
| `/book revenue [YYYY-MM]` | สรุปรายได้รายเดือน |
| `/book export` | ส่งออก bookings.csv |

## ติดตั้ง

```
/plugin install booking-system-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. แปลงวันที่หลายรูปแบบ รวมปี พ.ศ.
2. เช็คช่วงเวลาซ้อนกัน (a1 < b2 และ b1 < a2) และหาช่วงว่าง
3. วาดตารางรายวันช่องละ 30 นาที
4. แผงตารางรายวัน
5. คำสั่ง /book และส่งออก CSV พร้อม BOM ให้ Excel อ่านภาษาไทยถูก

## หมายเหตุ

เปิดให้จองช่วง 08:00-22:00 แก้ได้ที่ค่าคงที่ OPEN และ CLOSE ข้อมูลอยู่ในเครื่องเดียว ถ้าต้องการให้ลูกค้าจองเองผ่านเว็บ ต้องทำเว็บแยก
