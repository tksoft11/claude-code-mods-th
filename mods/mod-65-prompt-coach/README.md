# Mod 65: Prompt Coach TH

โค้ชเขียน prompt: ให้ Haiku ดูว่าคำสั่งกำกวมจนอาจทำผิดทางไหม (ไม่บอกไฟล์ พฤติกรรม หรือขอบเขต) โหมด ask จะถามกลับด้วยหน้าต่างเลือกแล้วเติมคำตอบต่อท้าย prompt ให้อัตโนมัติ โหมด hint ส่งทันทีแต่บอกว่าขาดอะไรไว้ฝึกครั้งหน้า พร้อมสถิติว่าลืมบอกเรื่องไหนบ่อย

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/coach ask` | ถามกลับก่อนส่งเมื่อ prompt กำกวม |
| `/coach hint` | ส่งทันที แต่บอกว่าขาดอะไร |
| `/coach off` | ปิด (ค่าเริ่มต้น) |
| `/coach check <prompt>` | ลองให้โค้ชดูโดยไม่ส่ง |
| `/coach stats` | สถิติ |

## ติดตั้ง

```
/plugin install prompt-coach-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. ให้ Haiku ตัดสินแล้วตอบ JSON สั้นๆ
2. ดัก prompt.submit และแก้ข้อความด้วย next({ ...e, text })
3. ถามกลับด้วย $.ui.ask (ปิดหน้าต่าง = ส่งตามเดิม)

## หมายเหตุ

ปิดไว้เป็นค่าเริ่มต้น เพราะโหมด ask ใช้ token และเพิ่มเวลาประมาณ 1-2 วินาทีทุกครั้งที่ส่ง prompt ข้ามคำสั่ง slash และข้อความสั้น
