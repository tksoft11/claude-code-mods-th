# Mod 68: Matrix Rain TH

ฝนตัวอักษรคาตาคานะ/ตัวเลขสีเขียวไหลลงมาแบบหนัง The Matrix ในแผงข้าง Claude Code หัวสายสว่าง หางค่อยๆ จาง ตัวอักษรกระพริบเปลี่ยนเอง พิมพ์ข้อความแล้วข้อความจะ "ถอดรหัส" ค่อยๆ ปรากฏกลางจอ เปลี่ยนสีได้ (เลือกยาเม็ดแดงหรือน้ำเงิน)

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `/matrix` | เปิดฝนตัวอักษร |
| `/matrix <ข้อความ>` | ถอดรหัสข้อความกลางจอ |
| `/matrix red\|blue\|green` | เปลี่ยนสี |
| `/matrix stop` | ปิด |

## ติดตั้ง

```
/plugin install matrix-rain-th --marketplace tksoft11/claude-code-mods-th
```

ต้องตั้ง `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` ก่อนเปิด `claude` (ดู [README หลัก](../../README.md))

## โค้ดสอนอะไร

เปิด [hooks/register.tsx](hooks/register.tsx) แล้วอ่านตามบทที่เขียนไว้ในคอมเมนต์:

1. สร้างสนาม: แต่ละคอลัมน์มีหยดฝนหนึ่งสาย
2. วาดหนึ่งเฟรม: หัวสายเกือบขาว หางจางตามระยะ
3. ข้อความถอดรหัสทีละตัวอักษร

## หมายเหตุ

วาดด้วย grid.tsx: บน terminal เป็น Raster (ช่องสีจริง) บน VS Code / Desktop / มือถือ แปลงเป็น SVG timer เดินเฉพาะตอนแผงเปิด
